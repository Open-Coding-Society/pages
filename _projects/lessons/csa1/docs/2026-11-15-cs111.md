## About CS 111

MiraCosta's catalog lists CS 111 as *Introduction to Computer Science I: Java*, a 3-unit course with no prerequisite that is accepted for CSU and UC credit. It meets 2 lecture hours and 3 laboratory hours a week. The catalog describes it as an introduction to object-oriented programming that covers language basics such as control structures and data types. See the [MiraCosta catalog entry](https://catalog.miracosta.edu/disciplines/computerscience/).

## CS 111 lessons in the Trimester 2 plan

The [Trimester 2 plan](/csa/trimester-2-plan/) teaches the class about the OCS system. Each lesson shows a real OCS feature, then the computer science topic behind it. The first two weeks map to CS 111.

| Week | OCS feature | CS 111 topic | Lesson |
|---|---|---|---|
