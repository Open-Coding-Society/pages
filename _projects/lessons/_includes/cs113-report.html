CS113 Instruction / Examples

This report follows MiraCosta's CS113 outline. Lessons are grouped by college topic, not by teaching week; a lesson can support several subtopics without becoming an additional assignment.

Teaching progression: Search and sort foundations are introduced early in CSA2 for AP preparation and Web project needs. Later DS2 work extends algorithm analysis and implementation. Week assignments remain in the shared CSA course plan; AP weeks review earlier work rather than introduce new assignments.

Differentiated depth: Advanced from-scratch CS113 implementations are opportunities for students ready to pursue those layers. Not every student is expected to complete every layer; DS2 ML/AI remains an alternative pathway.

Weeks and reference status come from current lesson metadata. Drafts are unfinished authoring work, not live assignments. Available examples and library usage do not establish implementation mastery or earned credit.
