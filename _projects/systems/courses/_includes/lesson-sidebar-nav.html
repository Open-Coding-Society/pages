{% comment %} Shows course progress and sprint/week/lesson list for navigation. Course data and posts must be available in page context. Weeks mirror the course timeline page: week badge, theme title, completion count, then the lessons for that week. Week themes and goals come from _data/.yml, e.g. Sprint1: start: 0 end: 4 0: theme: "Onboarding & Readiness" goals: ["Tool Setup", "Scrum Habits"] Blogs, each sprint's intro, and each week's intro (its learning goals) are pages of their own, made by _plugins/lesson_player_pages.rb. The URLs below must match the ones that plugin gives them: //blogs/ //sprint-/ //week-/ Expects lessonsByWeek, this course's lessons grouped by week, from _layouts/post.html. Contracts used by the sidebar script in _layouts/post.html: - #sprint-{i}-lessons and #chevron-{i} -> toggleSprint() - .lesson-item -> a step for Prev / Next and the pager - .lesson-item[data-lesson-id] -> a lesson, for completion tracking - .lesson-status-icon -> per-lesson complete/incomplete - [data-week-group] [data-week-count] -> per-week completion count Sets currentWeekUrl when it draws the page's own week, for the top bar's week crumb. A lesson whose week is in no sprint has no week page, so it stays blank. The script at the bottom of this file hides and shows the sidebar, for the button in _includes/lesson-topbar.html. {% endcomment %}
