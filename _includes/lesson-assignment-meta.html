{% comment %} Renders above the Submit Assignment box on any page with `assignment: true`. Two things a submission needs that the old form never asked for: 1. WHERE IT SITS IN THE COURSE. "4.2" means unit 4, chapter 2. The submissions dashboard groups by unit, so without this every submission lands in one undifferentiated list and a student cannot see how a whole unit went. 2. WHEN IT IS DUE. The date input refuses today and anything earlier -- work set at 8am and due at 3pm is not an assignment, it is an ambush. The floor is tomorrow, enforced both by the `min` attribute and by a check on submit, because `min` alone is advisory in some browsers. A lesson can fill these in ahead of time with `unit:`, `chapter:` and `due:` in its front matter. When it does not, the fields start empty and whoever is running the lesson picks. Nothing here is required to submit -- a student who just wants to hand work in can ignore the whole block. The options come from _data/csa_units.yml, which the dashboard reads too. {% endcomment %}
