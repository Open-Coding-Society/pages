Key Engineering Takeaways
GitHub API Rate Limiting
Unauthenticated requests are limited to 60/hour. Using GraphQL queries and caching dramatically reduces request count compared to REST polling.
Canvas Heatmaps vs SVG
Canvas renders faster for large datasets, but SVG allows interactive tooltips. Hybrid approach: render base heatmap in Canvas, overlay interactive layer in SVG.
Assessment Data Validation
Store quantitative ratings (0-5) separately from qualitative text. Validates slider values on submit, not on input change, to avoid lag on range inputs.
Time-Series Aggregation
Pre-aggregate monthly summaries at write time, not query time. Cuts trendline calculation from seconds to milliseconds when viewing multi-year growth.
