Research Area 2 · Object Detection

Research 2: YOLO Object Recognition

Evaluating bounding-box object classification, confidence estimation, classroom dataset curation, and baseline detection accuracy.

Research Question 2

Can a YOLO-based detector achieve at least 80% classification accuracy on core classroom object classes under varying angles, distances, and ambient lighting conditions?

Acceptance & Test Cases

  • Train and evaluate YOLO on six core classroom classes: chair, table/desk, laptop, backpack, bottle, and book
  • Achieve at least 80% precision and recall on a held-out, manually annotated classroom test dataset
  • Output normalized bounding box coordinates and calibrated confidence scores for each detected object
  • Filter transient false-positive detections with adaptive confidence thresholding
  • Separate classification uncertainty from spatial tracking uncertainty in downstream records
Classroom Detection Scope
Target ClassCategoryDetection Challenges
Chair Furniture (Fixed/Movable) Complex wireframes, overlapping stacks, and varied orientation angles.
Table / Desk Furniture (Fixed) Large planar surfaces, edge occlusions caused by resting laptops and backpacks.
Laptop Equipment (Portable) Open vs. closed state geometry differences, screen reflection glares.
Backpack Personal Asset (Portable) Deformable shape, varied textures and colors, placement on chairs or floor.
Bottle / Mug Small Object Specular reflections on stainless steel/clear plastic, partial hand occlusions.
Book / Binder Small Object Flat profiles when lying down, easily confused with paper stacks or laptops.
Dataset & Evaluation Strategy
  • Annotation Split: Establish a clean 70/15/15 train/validation/test split on high-resolution classroom images.
  • Data Augmentation: Apply brightness, contrast jitter, perspective warping, and cut-out transforms to simulate classroom clutter.
  • Future Extension: Material classification (wood, metal, polymer, glass) to be integrated as a secondary classifier head once object localization stabilizes.
