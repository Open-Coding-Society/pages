Research Question

Can a low-cost Raspberry Pi–based UHF RFID system, using tamper-evident computer-mounted tags and front/back doorway detection, reliably establish classroom device presence and contribute to student presence determination when correlated with an existing camera-spatial system and class registration/bell-schedule data?

Acceptance / Test Cases

  • 60×40 ft trial room, two-door layout (front + back), UHF reader(s) positioned to distinguish entry side
  • Per-period expected enrollment is known and used (e.g. Period 2 = 28 vs Period 5 = 34)
  • Bathroom / temporary-exit scenario: device stays in room, student leaves and returns, correctly resolved as temporary absence, not "left early"
  • Tamper scenario: tag physically removed from device → tag reports invalid/tampered rather than silently going unread
  • Tag lifecycle: a tag can be re-registered to a new device/student, and the old tag is retired without losing historical attendance data
  • Reads outside the bell-schedule attendance window are logged but excluded from attendance calculations
  • Opt-out flow: a student who declines face scanning still gets correct device-only presence tracking, with no false anomaly/tamper flags
  • Bag-orientation test: a tagged laptop inside a closed backpack reads reliably at the door regardless of which way the tag happens to be facing (currently unresolved — see Hardware section)
Design Decisions & Rationale
Design featureWhy
Tag mounted on the student's computerA laptop is less likely than a wearable badge to be left in a backpack/locker — it's the more reliable proxy for "this student is in the building."
RFID reading = device presence onlyA laptop can sit in the room while the student steps out (bathroom, etc). Device presence and student presence are different signals that must be tracked separately.
Camera (existing face-scanning system from Rohan) = required correlation inputStudent presence can only be established by combining RFID (device) with camera (person), not from RFID alone.
Expanded presence state machineCorrelating two signals produces states beyond a simple binary, e.g. device present + student temporarily absent.
Reads only counted inside a bell-schedule-defined attendance windowPrevents a tag being read hours later (e.g. hallway walk-through) from being misread as attendance.
Per-period expected enrollment (e.g. Period 2 = 28, Period 5 = 34)Presence has to be evaluated against the correct expected population for that period, not a global student list.
Tag has a lifecycle: registration → active → tampered/lost → reissued/retiredTags will be lost, damaged, or reassigned; the system needs an explicit process for that, not just a static mapping.
Tamper-evident tag (antenna breaks on removal)Prevents a student handing their tag to someone else or moving it between devices to game the system.
UHF RFID (865–928MHz), meter-range doorway/room detectionTags live on laptops sitting somewhere in the room, not badges tapped against a reader — needs multi-meter read range, which only UHF provides.

Attendance Window Logic

The bell schedule doesn't just define start/end times for tardy math — it defines a window during which reads count as attendance at all.

sequenceDiagram
    participant Bell as Bell Schedule
    participant Win as Attendance Window
    participant Door as Door Sensors (RFID)
    participant Cam as Camera System
    participant Eng as Correlation Engine

    Bell->>Win: Period starts -> window opens
    loop While window is open
        Door->>Eng: tag read (device event)
        Cam->>Eng: face/spatial event (student event)
        Eng->>Eng: correlate device + student signals
    end
    Bell->>Win: Period ends -> window closes
    Note over Eng: Any tag/camera event outside the window is logged but NOT counted as attendance

On-metal UHF tag (anti-metal, pack of 10) ISO18000-6C, EPC Class1 Gen2, waterproof Confirmed good by teacher for laptop-lid mounting — standard UHF tags detune badly near metal. Amazon
Standard adhesive UHF inlay tag, Alien H3 chip (pack of 100) ISO18000-6C, long range, ~$0.15–0.25/tag at this quantity Teacher recommends Alien H3 or Impinj Monza 4/5 chips — larger inlays hit 3–4m range; micro/button tags drop to 1–2m. Use on non-metal mount points (plastic bezel/underside). Amazon
📶 Read range and orientation: at 20–26dBm with the whip antenna above, expect a 2–4m read range — enough for a single door-table setup. The whip radiates in a ring perpendicular to its body, so tags read best held parallel to the antenna, not pointed at its tip; this needs to be part of the test protocol, not just the hardware spec.
⚠️ Open problem — computer-in-bag orientation: when the tagged laptop is inside a closed backpack, there's no guarantee the tag faces the reader, and read reliability drops sharply if it doesn't. Not yet solved — options to test: multiple reader antennas at different angles around the door, a standardized "tag pocket" location in the bag, or accepting a lower catch rate and relying on the camera signal to cover the gap.
📐 Scaling to the full room: the whip antenna above is sized for a single door-table test, not whole-room coverage. Covering the full classroom will need a larger/higher-gain antenna (or multiple antennas) and a real packaging/enclosure plan — flagged by the teacher as the next hardware step once the door-table rig is validated.
Dependencies & Open Questions
  • Camera system interface: what does Rohan's face-scanning system expose (API? event stream? file?) — needed to define the Camera Events integration contract, including how it reports a student who has opted out.
  • Budget/approval: hardware purchase (HAT, cable, antenna, tags) still needs sign-off.
  • Bag-orientation reliability: no confirmed mitigation yet for tag orientation inside a closed backpack — see Hardware section.
  • Tag mounting standard: decide on a single mounting spot on the laptop (e.g., underside near a plastic vent) so tag type (on-metal vs standard) can be standardized across all devices.
  • Room measurements: get actual dimensions/door layout of the confirmed classroom to size the eventual full-room antenna upgrade.
