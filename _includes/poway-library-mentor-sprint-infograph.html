About This Sprint

Industry professionals and parent volunteers are now coming into the CSA classroom to mentor student capstone teams. The platform previously had no role for this: mentors either got full teacher access or nothing. This sprint adds ROLE_MENTOR end-to-end: backend security config, frontend nav gating, a Google-verified signup path so mentors don't need a PUSD account, and a scoped project view showing only the teams they're assigned to.

Impact
  • Mentors can join the platform without a school account: verified by Google OAuth instead
  • Mentor access is scoped server-side: they see only their assigned projects, nothing else
  • Real-time chat lets mentors communicate with student teams between visits
  • Verified password reset removes the need for admin intervention when students forget credentials
  • GitHub ID validation prevents a common signup mistake that breaks the grading pipeline

Role & Permission Hierarchy

  • Submit assignments
  • Join group chats
  • Access course content
→

  • All Student perms
  • View all grades
  • Grade assignments
  • Manage groups
→

  • View assigned projects only
  • Chat with project teams
  • Google OAuth signup
  • No grade access

Admin
  • All role management
  • Approve mentor accounts
  • Assign mentors to projects
  • Full platform access

Features Built This Sprint

ROLE_MENTOR (Spring Security)

New role seeded in ModelInit and wired through Spring Security's filter chain. Mentor-specific routes return 403 to any other role: the server, not the browser, decides what a mentor may see.

Mentor Project Dashboard

/mentor lists only the capstone groups a mentor is assigned to (GET /api/groups scoped server-side). Clicking a project opens the group chat using the same SockJS/STOMP pattern as lesson chat.

Google OAuth Mentor Signup

Signup triggers Google account verification before submitting. PUSD student emails get immediate access; all others wait for admin approval. Google Sign-In added inline with the existing form.

"My Projects" Nav Link

nav/homejava.html shows "My Projects" when the account holds ROLE_MENTOR. The roles check was also hardened to guard against a null roles array that would previously throw at login.

OAuth + Student ID Password Reset

/support hosts a step-by-step reset wizard: verify Google account, confirm student ID, set new password. JWT tokens invalidated immediately on change. Reset ticket creation is rate-limited.

GitHub ID Validation

Inline validation rejects 7-digit numbers entered as GitHub usernames. Pattern check fires on every keystroke with an aria-live error span: no form submission needed to catch the mistake.

Password Complexity Enforcement

Reset wizard now enforces complexity rules before accepting a new password. Matches the requirements already in place at signup: one consistent policy across all credential flows.

Support & Troubleshooting Pages

/support replaces the old buried submenu with a dedicated top-level tab. A separate troubleshooting setup guide was added for common student environment issues, linked directly from nav.

Real-Time Team Chat

Mentor project view reuses the SockJS/STOMP WebSocket pattern from lesson_chat.html. Mentors send and receive messages in their assigned group's existing channel: no new infrastructure needed.

Future Goals

Planned

Admin Role Promotion UI

Admin-facing interface to approve pending mentor accounts and promote users from Student → Mentor or Mentor → Admin directly from the person management table, without needing API access.

Planned

Mentor Activity Dashboard

Summary view for mentors showing recent messages, session dates, and student milestone progress across all assigned projects: giving context before each visit without asking the teacher.

Planned

Mentor Visit Scheduling

Calendar integration letting mentors book their own classroom visit slots. Blocks appear on the shared class calendar and trigger an email reminder to the student team 24 hours before.

Planned

Mentor Approval Notifications

When an admin approves a pending mentor account, the platform automatically emails onboarding instructions and a /mentor link: removing the manual follow-up that currently falls on the teacher.

Planned

Public Mentor Directory

A browsable page listing active OCS mentors with their subject expertise and availability. Students and parents can request a mentor match directly, expanding the pipeline beyond word-of-mouth.

Planned

Mentor Session Notes

Mentors can log structured notes after each visit: goals covered, blockers, next steps. Notes are visible to the teacher but not other students, creating a lightweight mentorship record per team.
