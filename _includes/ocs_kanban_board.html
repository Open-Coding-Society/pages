{% comment %} Kanban board: a team's GitHub project board, live, on any page. {% raw %}{% include ocs_kanban_board.html url="https://github.com/orgs/UGRC-CSA/projects/1" filter="Team" %}{% endraw %} Options: url the board's address on GitHub (required). It has to be a public board owned by an organization (github.com/orgs/...): the page reads it without signing in, and GitHub keeps a personal board's cards for signed-in users. A team without an organization can give its repository's issues instead (github.com///issues): closed issues are Done, assigned ones In progress, the rest To do, and a label with a stage's name (in review, backlog) moves a card to that column. filter a single-select field to filter cards by, e.g. Team default: no filter (each option that has cards becomes a button; for a repository's issues, filter="Assignee" filters by person) title the heading default: the board's name columns the capstone's own changes to its board's columns, a list from its page data (columns=data.Board.columns). Each entry names a status and gives it a label (its own column, by that name), a stage (into that stage's column), collapsed: true or false, or hidden: true. See "Kanban board" in _sass/open-coding/README.md. The stages, field names and everything the board says are in _data/kanban.yml. Its defaults go on the page once, and each board's columns list inside its section, both as JSON for the script, with every "<" escaped so no value can end the script element early. The board loads itself (assets/js/kanban-board.js) when it scrolls near the screen, and keeps a copy for 10 minutes. The frame, filters and toggle are existing OCS elements (ocs__card, ocs__links, ocs__btn, ocs__toggle, ocs__status-pill, ocs__text); the columns and cards are the ocs__kanban element (_sass/open-coding/elements/kanban/), whose names also hold up inside a capstone's *-infograph include.
