{% comment %} Kanban board: a team's GitHub project board, live, on any page. {% raw %}{% include ocs_kanban_board.html url="https://github.com/orgs/UGRC-CSA/projects/1" filter="Team" %}{% endraw %} Options: url the board's address on GitHub (required). It has to be a public board owned by an organization (github.com/orgs/...): the page reads it without signing in, and GitHub keeps a personal board's cards for signed-in users. A team without an organization can give its repository's issues instead (github.com///issues): closed issues are Done, assigned ones In progress, the rest To do, and a label with a stage's name (in review, backlog) moves a card to that column. filter a single-select field to filter cards by, e.g. Team default: no filter (each option that has cards becomes a button; for a repository's issues, filter="Assignee" filters by person) title the heading default: the board's name The board loads itself (assets/js/kanban-board.js) when it scrolls near the screen, and keeps a copy for 10 minutes. The frame, filters and toggle are existing OCS elements (ocs__card, ocs__links, ocs__btn, ocs__toggle, ocs__status-pill, ocs__text); the columns and cards are the ocs__kanban element (_sass/open-coding/elements/kanban/), whose names also hold up inside a capstone's *-infograph include. The parts the script shows and hides are plain wrappers, because ocs__ elements that set display beat [hidden]. {% endcomment %} {% assign ocs_kanban_title = include.title | default: "Project board" %}
