Research Area 3 · Instance Segmentation

Research 3: SAM 3 Segmentation

Refining coarse bounding boxes into pixel-accurate segmentation masks, separating foreground objects from cluttered classroom backgrounds.

Research Question 3

How effectively can SAM 3 convert bounding box detection prompts into precise pixel masks under CPU-bound execution without exceeding the target 10-second processing cycle?

Acceptance & Test Cases

  • Pass YOLO bounding box coordinates as prompt boxes to SAM 3 to generate binary pixel masks
  • Isolate foreground object boundaries cleanly from complex textured backgrounds (e.g., desk grain, floor tiles)
  • Produce encoded binary mask representations for lightweight storage and downstream spatial comparison
  • Benchmark CPU inference time across frame resolutions (720p, 1080p, 4K) to preserve latency bounds
  • Validate mask stability across sequential captures for stationary classroom furniture
Compute Constraints & Optimization
Current Hardware Constraint: The primary Linux host runs inference on a multi-core CPU without a dedicated NVIDIA GPU. Efficient prompt-based inference and resolution scaling are essential to maintain the 10-second capture loop.

Open Questions & Next Steps
  • Quantization & ONNX: Evaluate int8 quantization or ONNX Runtime CPU acceleration to reduce segmentation latency.
  • Prompt Refinement: Add positive/negative centroid point prompts to prevent mask leakage between adjacent desks.
