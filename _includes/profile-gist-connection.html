How to get a GitHub token
  1. Sign in to the GitHub account you want to own your Gists. You do not need to create a Gist first.
  2. Open New fine-grained personal access token. Give it a name such as OCS Gist submissions, choose an expiration, and select your personal account as the resource owner.
  3. Keep repository access at Public repositories; no additional repository permissions are needed.
  4. Under Permissions, select Account (not Repositories), then Add permissions → Gists → Read and write.
  5. Click Generate token, copy it, paste it into the field below, and click Save token. GitHub only shows the token once.

Alternatively, create a classic token with only the gist scope selected.

Treat your token like a password: never share it or commit it. When it expires, create a new one and use Replace token here.

Use a fine-grained token with Gists: write, or a classic token with the gist scope. Create a GitHub token. Connecting verifies identity; GitHub checks write permission when you export.

Gists are unlisted, but anyone with the link can read them. Disconnect removes the token from OCS; revoke it separately in GitHub settings.
